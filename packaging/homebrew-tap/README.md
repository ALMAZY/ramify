# ALMAZY Homebrew tap

```bash
brew tap almazy/tap
brew trust almazy/tap          # Homebrew 6+ asks you to trust third-party taps once
brew install --cask ramify
```

Update with `brew upgrade --cask ramify`.

| Cask | App |
|---|---|
| `ramify` | [Ramify](https://github.com/ALMAZY/ramify): a keyboard-first mind map for fast notes |

The cask file is generated automatically by the Ramify release workflow.
